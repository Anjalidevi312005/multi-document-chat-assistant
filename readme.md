# Multi-Document Chat Assistant

AI-powered document Q&A assistant built with Python, Streamlit, and Gemini API.

## Features
- Upload PDF documents
- Extract and process text
- Ask questions about uploaded documents
- AI-powered summarization and rewriting
- Gemini API integration

## Tech Stack
- Python
- Streamlit
- Google Gemini API
- scikit-learn
- PyPDF
